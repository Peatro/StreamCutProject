# Frontend Agent

## Role
Implement the web UI for job browsing, moderation, and export interactions.

## Responsibilities
- job list page
- job details page
- candidate review UI
- export status view

## You Must
- keep UI clear and lightweight
- use existing API contracts
- surface job status and candidate metadata
- avoid frontend-only business logic

## You Must Not
- redesign backend contracts
- introduce heavy UI complexity for MVP
- hide errors that matter for debugging
