# Data Models

## vod_job
Represents a processing job for one VOD.

Fields:
- id
- source_type
- source_url
- original_filename
- status
- created_at
- updated_at
- started_at
- finished_at
- error_message
- duration_sec
- language
- storage_video_path
- storage_audio_path

## transcript_segment
Represents a transcribed speech segment.

Fields:
- id
- job_id
- start_sec
- end_sec
- text
- word_count

## silence_segment
Represents a silence interval.

Fields:
- id
- job_id
- start_sec
- end_sec
- duration_sec

## analysis_window
Represents one scored sliding window.

Fields:
- id
- job_id
- start_sec
- end_sec
- speech_density
- silence_ratio
- emotion_hits
- continuity_score
- total_score

## clip_candidate
Represents a candidate clip generated by the system.

Fields:
- id
- job_id
- start_sec
- end_sec
- score
- transcript_excerpt
- moderation_status
- moderator_note
- exported_clip_path

## job_event
Represents a status or processing event.

Fields:
- id
- job_id
- event_type
- message
- created_at
