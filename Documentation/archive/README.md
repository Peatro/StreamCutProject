# Archive Policy

## Purpose

This directory is reserved for documentation that should remain in the repository for historical or audit reasons but should no longer appear as active project guidance.

---

## Move A Document Here When

- it no longer reflects current project reality
- it still has historical value
- keeping it in the active docs root creates confusion

---

## Do Not Archive

- current backlog truth
- current runtime contract
- current release gate documents
- current architecture roadmap

---

## Before Archiving

Make sure:

- the active replacement document exists
- the document is referenced in `Documentation/legacy-notes.md` or `Documentation/doc-index.md`
- no current process still depends on the archived file as a source of truth
