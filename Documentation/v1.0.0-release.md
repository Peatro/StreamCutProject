## Known Limitations
- The service is single-tenant and uses one configured operator credential set.
- Zero-downtime upgrades are not supported.
- Source videos under `APP_STORAGE_LOCAL_ROOT` are not backed up by default.
- Automatic retry, backoff, and dead-letter semantics are still post-`v1.0.0` work.
- Export still shares the `processing-worker` pool instead of using a dedicated worker role.
- The first processing run on a cold host still depends on downloading the transcription model when `HF_TOKEN` is not configured.
